## 🤝 How to Contribute

Contributions from developers, researchers, and open-source advocates are warmly welcome! If you know of an official government API, open dataset, or public data portal that should be included, please follow these steps:

1. **Fork the Repository**: Click on the **Fork** button at the top right of this repository.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b add-new-portal
   ```
3. **Add Your Entry**:
   - Locate the most relevant of the 11 categories.
   - Insert a new row in the Markdown table keeping numerical order in `Sr. No.`.
   - Ensure the name links directly to the official `.gov.in`, `.nic.in`, or verified institutional website using `[Name](URL)`.
   - Write a crisp, value-driven description highlighting what the endpoint/portal offers developers.
4. **Verify Guidelines**:
   - Only official portals, sanctioned open datasets, or verified developer programs are accepted.
   - Please avoid unofficial scrapers, expired links, or third-party wrappers with non-transparent sourcing.
5. **Commit and Push**:
   ```bash
   git commit -m "feat: add <Portal-Name> under <Category>"
   git push origin add-new-portal
   ```
6. **Submit a Pull Request**: Open a PR with a brief summary explaining the newly added resource.
